<h3 align="center">Coffee, code, repeat.</h3>

I spend most of my time wrangling tabular data with Python, Pandas, and SQL. Lately I've been pulling DuckDB into more of my workflows because it handles local analytics without the overhead of spinning up a database server. I'm interested in the unglamorous parts of data work — cleaning, pipeline reliability, making sure numbers actually add up.
